# Bus Bhai Hyderabad 🚌

Free Android bus app for Hyderabad and Telangana.

- Search TGSRTC city routes (290U, 10H, 219…) and stops, in English or Telugu
- Offline map of all of Telangana, no data needed to browse
- Nearby stops from your location
- Live bus positions shared by riders on the same bus, no login
- Light, dark and Telugu modes, no ads, no tracking

## Download

**[Download the APK (v1.0.6, 4.9 MB)](https://github.com/sniff-yt/Bus-bhai/raw/main/BusBhaiHyderabad-v1.0.6.apk)**. Open it on your phone and allow installs from unknown sources.

Route data comes from TGSRTC's open timetable, so district coverage is still thin. Open an issue if a route is wrong or missing.

Map data © OpenStreetMap contributors.
